### 💻 Projetos em destaque

#### 🏥 Sistema de Clínica Médica

Sistema web desenvolvido para gerenciamento de **pacientes, médicos e consultas**, com operações de cadastro, edição, visualização e remoção de dados.

**Tecnologias:** React, JavaScript, Ant Design e LocalStorage.

🔗 [Ver projeto](https://github.com/matheusgg18/Sistema-de-Clinica-Medica)

---

#### 🛒 MultiLojas Marketplace

Plataforma de marketplace desenvolvida para permitir que diferentes empreendedores gerenciem suas lojas dentro de um mesmo sistema.

O projeto utiliza uma arquitetura com **front-end e back-end separados**, incluindo API e banco de dados.

**Tecnologias:** React, Python, Django, Django REST Framework e PostgreSQL.

🔗 [Ver projeto](https://github.com/matheusgg18/multilojas-marketplace)
